## What is it?

If you're looking to build an AI chat app with agentic capability, you've come to the right place. "hmmm" is an open source general purpose chat app ready to be shaped to fit your needs.

🔗 Live demo -> [start-faster.com](https://www.start-faster.com)

## What's included

- 🧠 Multi-model support via Open Router
- 🖼️ Image generation, editing, and analysis
- 💾 File storage
- 📄 Document analysis
- 🌐 Web search
- 🌦️ Weather forecasting
- 🎤 Voice transcription
- 💻 Code generation
- 🧊 AR/VR (experimental)
